# Каталог 0.1.0

| Раздел | Что реализовано |
|---|---|
| Матч | 2×1; подготовка/поиск/пауза/завершение; 3 акта; поимка без убийства |
| Укрытие | Серверная блокировка движения, скорости, изменения позиции, телепортации, транспорта и урона; частный якорь клиенту прячущегося |
| Экономика | Общие разведданные 5/15; восстановление 45/30 с; стоимость 1/2/4/6/8; командные, индивидуальные и областные cooldown |
| Геометрия | Восток/юг, высота, круг, прямоугольник, сектор, горизонтальная дистанция, пеленг; пересечение консервативных ограничений |
| Наблюдения | Блок в сфере: центр блока в радиусе 4 от точной позиции; точный/выбранный биом на высоте; типы структур по границам частей |
| Локальные подсказки | Неподвижное безопасное животное на 30 с; фейерверк из частиц до первого перекрытия; снимок 320×180 RGB |
| Снимок | Только окно игрового мира после возврата своей камеры; HUD и меню скрываются; 11 частей ≤16000 байт, 20 с на передачу; однократный возврат без награды при неудаче; в игре не записывается на диск |
| Компенсация | 1 череп: прогресс 2 покупки; 2/3/4/5: обычная/усиленная/редкая/эпическая категория; выбор 1 из 3; ограниченная рука |
| Карты | Ботинки, запрет спринта, шум, радиомолчание, карантин, запрет уровня 5, добыча камня, визит в точку, приманки |
| Смерть | Одна награда на факт смерти; задержка возрождения; оставшийся инвентарь и помехи сохраняются |
| Киты | Три случайных предложения из четырёх для каждой роли; ограниченные способности, без перемещения прячущегося |
| Испытание | Добровольный период без покупки подсказок; заряд крыльев; полёт до 12 с и безопасное снижение |
| Сохранение | Снимок правил/контента, роли, карты, предложения, экономика, эффекты, задания, история и метки; активный матч после рестарта на паузе |
| Расширение | JSON-каталог + зарегистрированные обработчики карт, задач, подсказок; проверка неизвестных обработчиков при запуске |

Числа — исходные настройки для плейтеста, не доказанный баланс. Точные упрощения и отсутствующие части: `LIMITATIONS.ru.md`.
