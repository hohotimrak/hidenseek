# Still Hunt / Неподвижная охота

Самостоятельный Fabric-мод асимметричных пряток **2 искателя × 1 неподвижный прячущийся**. Целевая версия: **Minecraft Java 1.21.8**, Java 21, Fabric Loader 0.17.3, Fabric API 0.134.0+1.21.8.

Это **тестовая сборка 0.1.0**, а не подтверждение выполнения всего исходного ТЗ. Реализован основной игровой срез и API расширения. Реальный многопользовательский плейтест ещё необходим; подробные пробелы перечислены в [LIMITATIONS.ru.md](docs/LIMITATIONS.ru.md).

## Установка

1. Установите Fabric Loader для **1.21.8**: https://fabricmc.net/use/installer/.
2. Положите `hidenseek-0.1.0.jar` и `fabric-api-0.134.0+1.21.8.jar` в `mods` **на сервере и у каждого из трёх игроков**.
3. Для LAN моды нужны и хосту, и подключающимся игрокам. Откройте мир по LAN с разрешёнными командами или используйте выделенный сервер с оператором.
4. После первого запуска сервер создаёт `config/stillhunt.json` и `config/stillhunt-content.json`. Меняйте их при остановленном сервере. Не обновляйте правила незавершённого матча: он использует сохранённый снимок.

Для первой проверки используйте отдельный мир. Арена — квадрат вокруг начальной позиции прячущегося; по умолчанию 1024 × 1024, Y от −64 до 320. Точка первого искателя становится точкой ожидания и возврата. Все участники должны находиться в одном измерении в Survival, рядом с выбранной ареной.

```text
/hunt start HiderName SeekerOneName SeekerTwoName
```

**H** открывает панель. Подготовка — 2 минуты, поиск — 45 минут. При недопустимом укрытии подготовка ждёт исправления и сообщает причину. Удар искателя по телу в пределах 3 блоков при прямой видимости завершает матч; убивать прячущегося не нужно.

Панель: карта, покупки подсказок, карты/наблюдение, киты. Колесо прокручивает длинные панели, на карте меняет масштаб; средняя кнопка перемещает карту; левая/правая создаёт личную/командную метку. Сначала «Предпросмотр», затем «Купить». Области задаются числовыми координатами; контур виден на карте. У круга радиусы 64/128/256, прямоугольник не уже 64 блоков, границы кратны 16, сектор — 128 × 128.

Оператор:

```text
/hunt pause
/hunt resume
/hunt stop
/hunt cancel_effects PlayerName
```

После отключения ключевого участника и после рестарта матч восстанавливается на паузе. Возобновление — `/hunt resume`. При продолжающемся отсутствии прячущегося или обоих искателей через 120 секунд фиксируется поражение отсутствующей стороны. Таймер матча не расходуется при выключенном сервере.

## Расширение

[Руководство по JSON-каталогу и Java API](docs/EXTENDING.ru.md). Карты и задания на существующих механиках добавляются без пересборки JAR. Новые серверные механики регистрируются через `ContentRegistry` и `HintRegistry`. Произвольный код из JSON не исполняется.

## Сборка и проверки

```powershell
# PowerShell 7; работает и для пути с кириллицей
./scripts/build.ps1
```

Для обычного ASCII-пути: `./gradlew.bat build` (Windows) или `bash gradlew build` (Linux). Результат — `build/libs/hidenseek-0.1.0.jar`. Нужен JDK 21; Gradle wrapper включён. Первая сборка скачивает зависимости. Версии зафиксированы в `build.gradle`.

`./gradlew.bat runServer -Psmoke` выполняет 9 интеграционных проверок на отдельном dev-сервере и останавливает его. Не запускайте smoke в рабочем мире. `./gradlew.bat runClient -PuiCheck` отрисовывает четыре тестовых экрана в настоящем клиенте, сохраняет кадры в `run-client/screenshots/` и закрывается. Эти фикстуры не являются многопользовательским тестом.
